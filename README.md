# MusicDSP

MusicDSP is an archive of algorithms, code snippets, and notes for audio signal processing. Much of the material was contributed by members of the [Music-DSP mailing list](http://sites.music.columbia.edu/cmc/music-dsp/).

## Browse the archive

- [Synthesis](Synthesis/README.md)
- [Analysis](Analysis/README.md)
- [Filters](Filters/README.md)
- [Effects](Effects/README.md)
- [Other](Other/README.md)

Each category lists its articles by title. Articles include their original author credits, code, and discussion. You can also browse the [archive files](files/).

## Contribute

Corrections and new contributions are welcome. To suggest a change, edit the article on GitHub and open a pull request. For a new article, add a Markdown file to the relevant category and link it from that category's README.
