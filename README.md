# MusicDSP

MusicDSP is an archive of algorithms, code snippets, and notes for audio signal processing. Much of the material was contributed by members of the [Music-DSP mailing list](http://sites.music.columbia.edu/cmc/music-dsp/).

## Browse the archive

- [Synthesis](Synthesis/README.md)
- [Analysis](Analysis/README.md)
- [Filters](Filters/README.md)
- [Effects](Effects/README.md)
- [Other](Other/README.md)

Each category lists its articles by title. You can also browse the [archive files](files/).

> [!NOTE]
> Comments come from the original MusicDSP archive. On articles with a discussion, select the comment count to jump to it, then expand the thread to read the replies.

## Contribute

Corrections and new contributions are welcome. To suggest a change, edit the article on GitHub and open a pull request. For a new article, add a Markdown file with a four-digit numeric prefix to the relevant category and link it from that category's README.
